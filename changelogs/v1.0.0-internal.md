# DevxyzIDE Version `1.0.0-internal` Changelog

## Important note

DevxyzIDE is created, developed, and owned by Jay-Ar Lee Espiritu. It is an
independent project and is not affiliated with the original AndroidIDE project.
DevxyzIDE is built on open-source software released under the GNU General
Public License v3.0.

## Additions

- Donate: the Donate action on the home screen now opens an in-app sheet with a
  GoTyme Bank InstaPay QR code — scan it with GCash, Maya, or any InstaPay bank
  app to support the project.
- About: an ownership disclaimer is now shown under the app name.
- The IDE's own Gradle plugins are now bundled in a local repository inside
  the app, so project builds can resolve them without downloading.

## Removals

- About: the Telegram group, Telegram channel, Contribute and Contributors
  entries have been removed.

## Bug fixes

- First-time setup: package installation now completes reliably, with built-in
  package lists and fallbacks when downloads fail.
- Fixed certificate errors that interrupted setup downloads.
- Gradle builds: fixed temp-directory handling and the stale daemon lock that
  could block a project from configuring after an interrupted build.
- The log sender plugin is now bundled with the app (it was previously
  referenced but missing, which broke builds that use it).

## Improvements

- About and Documentation links now point to the DevxyzIDE GitHub repository,
  and the contact email is now businessdevgithubjepong@gmail.com.
- About: the version line now shows the real app version, marked (official),
  and the header layout has been tightened.

We believe that you'll have a delightful experience using DevxyzIDE `1.0.0-internal`!
